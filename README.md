# UMNR — Fashion-Tech SaaS Platform

> Technical documentation and project delivery case study for a multi-tenant fashion-tech SaaS platform.

## Project Overview

UMNR is a SaaS platform designed to centralize and streamline fashion agency operations, including talent management, castings, bookings, scheduling, communication, documents, and analytics.

This repository demonstrates how product requirements were translated into structured technical documentation and a project delivery framework.

## Portfolio Focus

**Technical Project Management & Technical Writing**

- Software requirements documentation
- Functional and non-functional requirements
- Role-Based Access Control (RBAC)
- Requirements traceability
- Project roadmapping
- Milestone planning
- Risk and dependency management
- Acceptance criteria
- Technical project documentation

## Delivery Approach

The project follows a dependency-driven delivery approach, beginning with authentication and access control before progressing through talent management, casting, booking, scheduling, communication, documents, analytics, and administration.

Requirements are tracked using unique identifiers to maintain traceability from definition through implementation and validation.
