# UMNR — Project Overview

## Project Summary

UMNR is a premium, multi-tenant SaaS platform designed for fashion agencies to manage their core operations from a centralized system.

The platform is designed to streamline talent management, talent discovery, castings, bookings, scheduling, communication, compliance tracking, and financial oversight.

The product supports desktop and tablet workflows for agency teams, with a mobile-focused experience for talent users.

## Project Objective

The objective of UMNR is to reduce operational fragmentation within fashion agencies by providing a unified platform for managing talent, castings, bookings, communication, documents, scheduling, and performance data.

## Core Product Modules

The documented system includes:

- Authentication and onboarding
- Agency and talent management
- Role-Based Access Control (RBAC)
- Main operational dashboard
- Talent profiles and discovery
- Casting management
- Booking management
- Calendar and scheduling
- Internal messaging
- Contracts and document management
- Analytics and reporting
- Administrative settings

## Primary User Groups

UMNR supports four primary user groups:

1. **Agency Admin / Manager**
2. **Casting Director**
3. **Operations / Staff**
4. **Talent (Model / Creative)**

Access to platform functionality is controlled according to each user's operational responsibilities.
