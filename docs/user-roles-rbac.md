# User Roles & Role-Based Access Control (RBAC)

## Overview

UMNR uses Role-Based Access Control (RBAC) to ensure that users only have access to the features and information required for their responsibilities.

The platform defines four primary user roles:

1. Agency Admin / Manager
2. Casting Director
3. Operations / Staff
4. Talent (Model / Creative)

## Agency Admin / Manager

The Agency Admin or Manager has the highest level of operational access within the platform.

### Key Permissions

- Manage system settings and billing
- Create, edit, and delete talent records
- Access financial and revenue dashboards
- Create and manage castings
- Create and edit bookings
- Access contracts and documents
- Access internal job-related communication
- Manage platform permissions

## Casting Director

The Casting Director primarily manages casting-related activities.

### Key Permissions

- Create and manage castings
- Search and shortlist talent
- Review talent submissions
- View assigned booking information
- Access communication related to assigned jobs

## Operations / Staff

Operations users support the day-to-day administration of agency activities.

### Key Permissions

- Create and edit talent records
- Create and edit castings
- Create and manage bookings
- Access relevant contracts and documents
- View operational financial information where permitted
- Access communication for assigned jobs

## Talent (Model / Creative)

Talent users have restricted access focused on their own profiles, availability, bookings, and assigned work.

### Key Permissions

- Manage their own profile
- View casting invitations
- View and confirm assigned bookings
- Sign personal contracts
- Access communication related to assigned jobs

## Access-Control Principle

UMNR follows the principle of least privilege. Users should only receive access to the functionality and information necessary to perform their assigned responsibilities.

Sensitive information, including contracts, rates, financial information, and identification records, is restricted according to the user's role and permissions.
